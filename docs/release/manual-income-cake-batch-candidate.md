# 手动收入条目编辑与 CAKE 批量调整候选

月度收支大盘现在可在同页抽屉新增手动收入，或修改选中条目的金额。未选中的历史记录、来源、备注和状态保留；草稿及停用条目不计入确认收入。保存成功刷新大盘收入与 ROI，失败不显示虚假的成功金额。继续使用既有手动收入服务、权限、月锁及审计规则。

CAKE 表格每页 20 条，五个金额列分别计算当前页合计，使用精确六位美元小数运算。目标空值不参与合计，最终 Revenue 明确标注为包含草稿的预览。支持逐项勾选、全选当前页、批量确认与停用；切换账号、月份或页面清除选择。刷新后仅保留版本仍有效的选择。

批量接口在服务端校验权限、账号、月份、版本、归属、原生收入基准与月锁，持有月份事务锁后整批写入并审计。任一记录或审计写入失败整批回滚。请求标识绑定所选记录及版本，重复提交返回已有结果。
