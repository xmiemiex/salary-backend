## 行为

月度大盘按 CAKE 账号＋月份显示独立人工核对栏，默认“未核对GMT+8时区佣金”。API 同步和整月覆盖不会自动确认人工核对，也不受此提示阻断。

有效已确认的原 SUB 调整显示“已有已确认调整（N 条）”，说明的是实际调整依据，不推断整个账号每一条已核对。普通草稿和停用不算，最后一条有效调整停用且无独立确认时恢复未核对。历史调整不回填虚构记录。

“已核对，无需调整”保存独立人工确认，不生成收入记录。确认范围在弹窗明确显示，并保存确认人、时间和该账号当月原生佣金的 SUB 聚合指纹。提交时检查页面指纹，阻止旧页面误确认；同值刷新保留，原生金额或 SUB 分布变化时显示待复核。有已确认或待复核调整时，必须走既有调整处理，不允许矛盾的无需调整确认。取消只撤销独立证据，不动收入和既有调整。

管理权限沿用 `super_admin + income.import`。确认/取消遵守锁月，事务使用已有月份互斥锁，写入与成功审计同事务；锁月竞争失败另记审计。收入公式和工资结算阻断规则没有扩展。

大盘“查看 / 调整”链接传递账号和月份，目标页已实现参数初始化；应用导航按 pathname 选择页面，保留 query 供筛选使用。
